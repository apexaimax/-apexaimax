# Anthony G.

Independent software builder creating practical tools for trustworthy digital workflows.

I focus on products where people need more than automation: they need control, clear boundaries, and evidence that a system did what it was supposed to do.

## Selected work

- **[VersionVault](https://github.com/apexaimax/version-vault)**  
  A browser-based tool for comparing file versions and surfacing meaningful changes.

- **Time-Glide**  
  Workflow-support software for organizing information and reducing repetitive documentation work.

- **FieldBridge Studio**  
  A private, review-first browser-extension project for mapping user-provided structured information into web forms only after explicit approval.

- **ProofRail**  
  A private project exploring verifiable approval boundaries for consequential software actions.

- **ForgeMind**  
  An in-progress engineering system for planning, coordinating, testing, and verifying software work.

## Working principles

- Build focused tools around real workflow problems.
- Keep people in control before software takes consequential action.
- Prefer clear documentation, repeatable tests, and honest limits over inflated claims.
- Treat privacy, security, compatibility, licensing, and ownership as things to establish with evidence.
